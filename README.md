# ระบบรับหนังสือราชการ (Official Document Reception System)

เว็บแอปรับหนังสือราชการสำหรับสถานศึกษา/หน่วยงานราชการ พัฒนาด้วย **Google Apps Script (GAS)** +
**Google Sheets** (ฐานข้อมูล) + **Bootstrap 5** + **SweetAlert2** รองรับมือถือเต็มรูปแบบ
พร้อมเมนูแถบล่าง (bottom navigation), ระบบเลขรับอัตโนมัติ และการประทับลายเซ็นลงเอกสารจริง

---

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|------|---------|
| `Code.gs` | จุดเริ่มต้น (`doGet`), `setup()`/migration, ยูทิลิตี้, เชื่อม Sheet/Drive, ปี พ.ศ., hash |
| `Auth.gs` | เข้าสู่ระบบ (รหัสผ่าน/PIN), session token, เปลี่ยนรหัสเอง |

| `Admin.gs` | จัดการผู้ใช้ 5 ระดับ, การตั้งค่า, ลายเซ็น, ตัวนับเลขรับ, สถิติ, activity log |

### ไลบรารีภายนอก (โหลดจาก CDN — ต้องมีอินเทอร์เน็ตครั้งแรก)
Bootstrap 5, Bootstrap Icons, SweetAlert2, ฟอนต์ Sarabun, **pdf-lib** (เขียนลายเซ็นลง PDF),
**@pdf-lib/fontkit** (ฝังฟอนต์ไทยใน PDF), **pdf.js** (พรีวิวหน้า PDF) — ไม่ต้องใช้ OAuth scope เพิ่ม

## วิธีติดตั้ง (Setup)

### วิธีที่ 1 — คัดลอกด้วยมือ
1. สร้าง **Google Sheet** ใหม่ → เมนู **Extensions → Apps Script**
2. สร้างไฟล์ให้ตรงตามรายการ — ไฟล์ `.gs` เป็น Script, ไฟล์ `.html` เป็น HTML (ไม่ต้องใส่ `.html`),
   ส่วน `appsscript.json` เปิด ⚙️ **Project Settings → "Show appsscript.json"** แล้ววางทับ
3. บันทึกทั้งหมด แล้วเลือกฟังก์ชัน **`setup`** → กด **Run** หนึ่งครั้ง (อนุญาตสิทธิ์ตามที่ขอ)
4. **Deploy → New deployment → Web app** → Execute as **Me**, Who has access **Anyone** → คัดลอก URL ใช้งาน

### วิธีที่ 2 — clasp
```bash
npm install -g @google/clasp
clasp login
clasp create --type sheets --title "ระบบรับหนังสือราชการ"
clasp push
clasp open      # รัน setup() แล้ว Deploy เป็น Web app
```

> ⚠️ แอปใช้ `google.script.run` จึงทำงานได้เฉพาะบน Google Apps Script — เปิดไฟล์ HTML ตรง ๆ จะไม่ทำงาน

> 🔁 **เมื่ออัปเดตเวอร์ชันที่มีฟีเจอร์ใหม่ (เช่น เลขรับ) ให้รัน `setup()` ซ้ำหนึ่งครั้ง** —
> เป็น migration ที่ปลอดภัย ทำซ้ำได้ จะเพิ่มคอลัมน์/ค่าตั้งต้นที่ขาดโดยไม่ลบข้อมูลเดิม

## ระดับผู้ใช้ (5 levels) และสิทธิ์
| Level | บทบาท | สิทธิ์หลัก | เห็นความลับสูงสุด | ดาวน์โหลด |
|-------|-------|-----------|------------------|-----------|
| 1 | ผู้ดูแลระบบ | ทุกอย่าง + จัดการผู้ใช้/log/เลขรับ | ลับสุดยอด | ทุกระดับ |
| 2 | ผู้บริหาร | รับทราบ/อนุมัติ/ส่งต่อ, ตั้งค่า, สถิติ | ลับสุดยอด | ทุกระดับ |
| 3 | หัวหน้างาน | รับงานที่ส่งต่อ, ดำเนินการ+ลงนาม | ลับ | ถึงระดับ "ลับ" |
| 4 | ครู | รับงานที่ส่งต่อ, ดำเนินการ+ลงนาม | ลับ | ถึงระดับ "ลับ" (ของตน) |
| 5 | เจ้าหน้าที่เอกสาร | บันทึกหนังสือรับเข้า | ทั่วไป | เอกสารของตน |

## ฟีเจอร์หลัก

### 1) บันทึกหนังสือรับเข้า
วันที่ระบบ (อัตโนมัติ), วันที่รับ, เรื่อง, ผู้รับ (ชื่อจริง level 5 ที่ login), รับจาก, ฝ่ายงาน,
หัวหน้างาน, ครู, ระดับความลับ, แนบไฟล์/ภาพสแกน — และ**ออกเลขรับอัตโนมัติ**

### 2) เลขรับอัตโนมัติ (running)
- รูปแบบ `เลข/ปีพ.ศ.` เช่น `378/2569` รันเพิ่มทีละ 1 และ**รีเซ็ตเมื่อขึ้นปีใหม่**
- ใช้ `LockService` กันเลขชนกันเมื่อบันทึกพร้อมกัน
- ตั้งค่าได้ที่ **ตั้งค่าระบบ → เลขรับหนังสือ** (กำหนดปี/เลขล่าสุด)
- **เติมเลขย้อนหลัง** ให้เอกสารเก่าที่ยังไม่มีเลข (ปุ่มสำหรับ admin) เรียงตามวันที่รับ

### 3) จัดการผู้ใช้ & ตั้งค่า
จัดการผู้ใช้ 5 ระดับ (เพิ่ม/แก้ไข/ลบ/รีเซ็ตรหัส), ตั้งค่าฝ่ายบริหาร/กลุ่มสาระ/หัวหน้า/ครู

### 4) ลายเซ็น
กำหนดลายเซ็นต่อ username (วาดบนจอ/อัปโหลด) — เมื่อประทับลงเอกสาร ระบบ
**ลบพื้นหลังขาวอัตโนมัติ + ย้อมหมึกเป็นสีน้ำเงิน**

### 5) อนุมัติ/รับทราบ + ส่งต่อ
level 1-2 รับทราบ/อนุมัติ → ส่งต่อ level 3-4 พร้อมวันที่ + ลายเซ็น + ตั้งระดับความลับ
(สาธารณะ/ทั่วไป/ลับ/ลับสุดยอด) เลือกตำแหน่งลายเซ็นบนเอกสารได้

### 6) ประทับลายเซ็น "ลงบนเอกสารจริง"
- **ไฟล์รูปภาพ** — ประทับด้วย HTML5 Canvas
- **ไฟล์ PDF** — เขียนลงหน้า PDF จริงด้วย pdf-lib (ข้อความไทยผ่าน fontkit + Sarabun)
- **พรีวิวสด** — เลือกหน้า/ตำแหน่ง, เลื่อนดูทุกหน้า (pdf.js), เห็นผลก่อนสร้างจริง
- **ตรารับหนังสือ** มุมบนซ้าย (จัดชิดขวา อักษรน้ำเงิน): ชื่อฝ่าย / รับที่ / ผู้รับ + ลายเซ็นเจ้าหน้าที่
- **ตราระดับความลับ** กลางบน + วันที่แบบไทย `30 พ.ค. 2569`
- ส่งออก/บันทึกเป็นไฟล์ฉบับลงนาม (แทนที่ไฟล์เดิม), ดาวน์โหลด PDF/รูป ตามสิทธิ์ความลับ

### 7) สถิติ
กรองตามระดับความลับ/สถานะ/ช่วงวันที่ แสดงแยกตามความลับ/สถานะ/ฝ่าย/เดือน
(เห็นเฉพาะเอกสารที่อยู่ในสิทธิ์ของผู้ใช้)

### 8) มือถือ
Responsive + bottom navigation ปรับเมนูตามระดับผู้ใช้

## ความปลอดภัย
- รหัสผ่าน/PIN เก็บแบบ **SHA-256 + salt** (ไม่เก็บ plaintext)
- Session เป็น token ใน `CacheService` อายุ 8 ชม. (ฝั่ง client เก็บใน `localStorage`)
- ทุก API ตรวจสิทธิ์ด้วย `requireAuth_(token, minLevel)` ก่อนเสมอ
- การมองเห็น/ดาวน์โหลด กรองตามระดับความลับเทียบระดับผู้ใช้ที่ฝั่ง server

## การปรับแต่ง
- เพิ่มฝ่าย/กลุ่มสาระ/หัวหน้า/ครู และตั้งเลขรับ ได้ที่หน้า **ตั้งค่าระบบ**
- สี/ตราระดับความลับ ปรับใน `Style.html` (`.badge-conf-*`)
- ตำแหน่ง/ขนาดลายเซ็นบนเอกสาร ปรับใน `Script.html` (`drawStamp`, `drawPdfStamp`, `drawReceiveHeader*`)
- เวลา session ปรับที่ `SESSION_HOURS` ใน `Code.gs`
